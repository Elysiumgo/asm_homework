C 源码与机器指令的对应关系
row / col 分别位于 [rbp-0x4] / [rbp-0x8]；编译器使用栈内存保存局部变量。
13×row 通过两次 ADD 和一次 SHL 计算，再与 'a' 和 col 相加。
内层和外层 for 循环分别由 CMP + JLE 控制；if (col < 12) 对应 CMP + JG。
putchar 的参数通过 ECX 传递，CALL 完成字符输出。
这份反汇编是 64 位 Windows 程序；两个 MASM 程序则是 16 位 DOS 程序。
