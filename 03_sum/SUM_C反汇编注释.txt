C 源码与机器指令的对应关系
n、i、sum 分别保存在 [rbp-0xc]、[rbp-0x8]、[rbp-0x4]。
输入范围检查由 CMP/TEST 和条件跳转完成。
for 循环的核心是 ADD 实现 sum += i，随后 i++，再用 CMP + JLE 判断是否继续。
printf 使用 %d 完成二进制整数到十进制字符的转换。
该反汇编属于 Windows x64；MASM 生成的四个 EXE 属于 16 位 DOS 程序。
