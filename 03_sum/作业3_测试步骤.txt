作业3 DOSBox 测试步骤

一、进入程序目录
在当前已经配置好的 DOSBox 中输入：
C:
CD \ASMHW
DIR SUM*.EXE

二、直接运行已经编译好的程序
SUMREG
预期输出：5050

SUMDATA
预期输出：5050

SUMSTK
预期输出：5050

SUMIN
看到 Input n (1-100): 后输入 100 并回车。
预期输出：Sum = 5050

还可以再次运行 SUMIN，分别输入：
1    预期 Sum = 1
10   预期 Sum = 55
0    预期提示 Invalid input. Enter 1-100.，随后可以重新输入
101  预期提示 Invalid input. Enter 1-100.，随后可以重新输入

三、重新汇编和链接（可选，用于证明源码可生成 EXE）
以 SUMREG 为例：
MASM SUMREG.ASM;
LINK SUMREG.OBJ;
SUMREG

其余程序把文件名依次替换为 SUMDATA、SUMSTK、SUMIN 即可。
MASM 显示 0 Warning Errors 和 0 Severe Errors，LINK 返回命令提示符，即表示生成成功。

四、C 语言版本
SUM_C.EXE 是 Windows 64 位程序，请在 Windows 中运行，不要放进 DOSBox。
运行后输入 100，预期显示 Sum = 5050。

五、程序含义
SUMREG：运行中的求和结果保存在 AX 寄存器。
SUMDATA：求和结果保存在数据段变量 RESULT。
SUMSTK：运行中的求和结果保存在栈顶。
SUMIN：使用 DOS 21H 中断的 AH=01H 功能逐字符读取输入，并检查 1~100 范围。
