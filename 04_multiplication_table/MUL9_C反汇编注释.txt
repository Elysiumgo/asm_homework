main 中 [rbp-0x4] 是 row，[rbp-0x8] 是 column。
CMP + JLE 控制内层循环，CMP + JG 控制外层循环，构成双重循环。
CALL print_item 对应 C 中的过程调用；print_item 末尾的 RET 返回 main。
print_item 中的 IMUL 对应 row * column。
