总结
----

1. C 语言的递归最终仍由 CALL、RET 和每层独立栈帧实现。
2. count 通过 ECX 传参，然后保存在当前层栈帧中，下一层使用 count-1。
3. 大整数数组避免 F(100) 超出普通整数范围。
4. sum 是局部变量，位于栈中；current、next 是全局变量，位于数据区。
5. 该文件是 Windows x64 程序的反汇编；FIBREC.EXE 则是 16 位 DOS/MASM 程序。
