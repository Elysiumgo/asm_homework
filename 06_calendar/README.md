# 作业 6：输出日历

## 1. 完成内容

- 从键盘输入年份 `1900~2099` 和月份 `1~12`。
- 输出指定月份的完整月历，星期顺序为 `Su Mo Tu We Th Fr Sa`。
- 正确处理闰年，尤其是 1900 年不是闰年、2000 年是闰年。
- 功能按过程拆分，并使用寄存器、数据段和栈三种传参方式。
- 使用 `MAIN_CODE`、`UTIL_CODE` 两个代码段；跨段过程使用 `FAR CALL/RETF`。
- 提供等价 C 程序及其实际反汇编注释。

## 3. 程序设计

### 星期计算

以 `1900-01-01` 是星期一为基准，令星期日到星期六分别为 `0~6`。从 1900 年累加到目标年份：平年使星期偏移 1，闰年偏移 2；再累加目标月份之前各月的天数，最后对 7 取余，得到该月 1 日的星期。

### 闰年规则

年份能被 400 整除，或者能被 4 整除但不能被 100 整除时为闰年。因此：

- 1900 年不是闰年；
- 2000 年是闰年；
- 2024 年是闰年。

### 参数传递比较

1. **寄存器传参**：`READ_NUMBER` 用 `DX` 接收提示字符串地址，返回值放在 `AX`；`IS_LEAP` 用 `AX` 接收年份。
2. **数据段传参**：`YEAR_VALUE`、`MONTH_VALUE`、`FIRST_DAY` 和 `DAYS_IN_MONTH` 便于多个过程共享，直观但可重入性较差。
3. **栈传参**：调用 `PRINT_CALENDAR` 前依次压入年份和月份，过程通过 `[BP+6]`、`[BP+4]` 访问，`RET 4` 清理参数。栈传参适合参数较多的过程，但必须保证偏移和清栈字节数正确。

## 4. 两个代码段和远调用

程序包含：

- `MAIN_CODE`：输入检查、日期计算和日历排版；
- `UTIL_CODE`：字符串、字符、整数输出和十进制输入。

从 `MAIN_CODE` 调用 `UTIL_CODE` 中的过程时，汇编器生成远调用。`CALL` 同时把返回的 `CS` 和 `IP` 压栈，过程使用 `RETF` 恢复两者。段内调用只需要保存 `IP`，使用普通 `RET`。

## 5. 短跳转、近跳转和远跳转

- 短跳转的位移只有 8 位，范围是 `-128~+127` 字节，适合附近的条件分支。
- 同一代码段内距离较远时使用近跳转，修改 `IP`，不修改 `CS`。
- 跨代码段调用或跳转需要同时改变 `CS:IP`，属于远调用或远跳转。

如果条件跳转目标超出短跳转范围，可以把条件取反，先跳过一条无条件近跳转，例如：

```text
JAE nearby
JMP far_target
nearby:
```

也可以把过长的过程拆分成多个小过程，既解决跳转距离问题，也改善结构。

## 6. 调试过程记录

### 输入和边界

输入过程使用 DOS `INT 21H/AH=01H` 逐字符读取并回显，遇到回车结束，同时忽略重定向测试中的换行符。检查 `1899`、`2100`、月份 `0`、`13` 以及非数字输入，程序会提示重新输入。有效边界 `1900`、`2099` 可以正常显示。

最初使用 `INT 21H/AH=0AH` 缓冲输入。在 DEBUG 脚本连续提供年份和月份时，第一次输入后的换行符会被第二次调用当成空输入，导致自动测试不稳定。后来改成 `AH=01H` 逐字符读取，显式忽略 LF，并在遇到 CR 时结束；键盘交互和文件重定向测试都能正常工作。这个问题说明输入设备和重定向文件的行尾处理可能不同。

### 日期和闰年

重点测试：

- `1900-02`：28 天；
- `2000-02`：29 天；
- `2024-02`：29 天；
- `2026-11`：1 日为星期日，与题目示例一致。

### 调用和栈

在 DEBUG 中观察 `CALL PRINT_CALENDAR` 前后的 `SP`：压入两个参数后 `SP` 共减少 4；近调用再压入 2 字节返回 `IP`。进入过程执行 `PUSH BP / MOV BP,SP` 后，月份位于 `[BP+4]`，年份位于 `[BP+6]`。末尾 `RET 4` 同时返回并清除两个参数。

跨段调用 `PRINT_STRING` 时，远 `CALL` 压入返回 `CS` 和 `IP`，`SP` 减少 4；`RETF` 后 `CS:IP` 和 `SP` 都恢复。


## 8. 学习心得

这次作业把“日期算法”和“过程调用的底层实现”结合起来。寄存器传参速度快但数量有限，数据段共享最直观但依赖全局状态，栈传参更灵活但必须准确维护栈平衡。段内近调用只保存 `IP`，跨段远调用则必须保存 `CS:IP`。另外，条件跳转的位移范围会影响程序组织方式，代码增大后需要合理安排标签或用反向条件加近跳转。
